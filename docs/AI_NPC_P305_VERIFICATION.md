# P3-05 · Перевірка акустики The Copy

## Автоматична перевірка

У PowerShell із кореня проєкту запусти `./tools/Verify-P305.ps1`. Якщо локальний UDP-клієнт не підключається, повтори з `-UseWebSockets`. За потреби передай `-UnityEditor` зі шляхом до Unity 6000.6.5f1. Скрипт запускає Unity в тимчасовій копії та зберігає `Logs/AI-NPC/P3-05-remote-<run>.log`. Параметр `-KeepWorkspace` залишає копію для діагностики.

Перевірка створює окремі NGO Host і Client у процесі Unity та використовує реальний локальний UTP. Тестовий префаб походить від `PlayerPlaceholder`. Стенд викликає фактичні RPC голосу та кроків із підставленими даними, перевіряє ID відправника в NPC і паралельну доставку звичайної події через NoiseDispatcher. Лог має містити `[P3-05] COMPLETE`, а Unity має повернути код 0. Тестові PCM і кроковий виклик покривають мережеву доставку. Захоплення мікрофона, ввід гравця та Relay перевіряються в ігровій сцені.

## Host і Client в ігровій сцені

Готова сцена з probe зберігається в [Assets/Tests/AI/P305_Acoustics_Local](../Assets/Tests/AI/P305_Acoustics_Local.unity). Подальші кроки також описують створення тестової копії з початкової сцени. Глобальний Build Settings залишається локальним налаштуванням перевірки.

### Автоматичний запис доказів у Unity Editor

Під час Play вибери серверний `P305_HearingProbe`. У його `CopyHearing` параметр **Auto log P3-05 evidence** за замовчуванням увімкнений. Inspector записує `[P3-05 AUTO]` раз на секунду, включно зі станом `none`. Інтервал змінюється в **Log interval (seconds)**, мінімум 0,1 с. Це періодичні знімки, тому короткий живий сигнал може завершитися між записами, але його пам’ять лишається доступною до TTL.

Натисни значок замка у верхньому правому куті Inspector, щоб закріпити його за probe. Автозапис працює, доки цей Inspector відображається, гра запущена й об’єкт заспавнений на сервері. Вимкнення перемикача зупиняє автозапис. Налаштування зберігаються в поточній сесії Editor. У наступних кроках замість натискання кнопки можна дочекатися автоматичного рядка. Кнопка лишається для додаткового знімка з префіксом `[P3-05 MANUAL]`.

Для завершення P3-05 потрібні два записи зі збірки після підключення ID. Перезбери Client і запусти Host з тієї самої версії коду. Голос із мікрофона та кроки мають показати ID віддаленого гравця. Тестовий свист `V` використовує окремий RPC і досі дає `anonymous`.

1. Використай тимчасову копію Unity-проєкту. Відкрий `Assets/Scenes/Networking_Sandbox.unity` і збережи копію сцени через **File → Save As** як `Assets/Scenes/P305_Acoustics_Local.unity`. У копії додай окремий об’єкт `P305_HearingProbe` із `CopyHearing` і `NetworkObject`. Постав його приблизно за 3 м від `SpawnPoint_2` із прямою видимістю. Залиши стандартні 18 м і 4 с. За потреби додай тестовий Cube на шарі **Ignore Raycast**, вимкни його та обери цей шар у **Occlusion Layers** компонента.
2. У тимчасовій копії відкрий **File → Build Profiles** і збери Windows Client із `P305_Acoustics_Local` як першою сценою. Запусти збірку з окремим логом, наприклад `& './Builds/P305/P305.exe' -logFile 'C:/Temp/P305-client.log'` після створення цієї папки для логів. У Unity Editor відкрий ту саму сцену й натисни **Play**.
3. В Editor натисни **СТВОРИТИ ГРУ (Гравець 1 — Хост)**. У Client введи код Relay та натисни **ПРИЄДНАТИСЯ ЗА КОДОМ (Гравець 2)**. На хості вибери `P305_HearingProbe` в Inspector. Кнопка **Log P3-05 evidence** записує ролі, список підключених ID, поточний сигнал і пам’ять. У тесті з двома підключеними гравцями віддалений ID — єдиний ID у списку, відмінний від серверного `0`.
4. Якщо обидва процеси використовують один фізичний мікрофон, вимкни `VoiceNoiseEmitter` лише на локальному гравці хоста з Owner Client ID 0 в Inspector під час Play. Потім вибери знову `P305_HearingProbe`. Говори в мікрофон з боку Client і впродовж 4 с натисни **Log P3-05 evidence** на хості. Очікується `PlayerVoice` з віддаленим ID і позицією Client. Для тесту кроків тимчасово приглуши мікрофон, якщо фоновий голос перезаписує пам’ять. Дочекайся `memory=[none]`, коротко пробіжи на Client з **Left Shift + W** та знову натисни кнопку впродовж 4 с. Очікується `PlayerFootstep` з тим самим ID та останньою почутою позицією.
5. Для згасання зафіксуй ще один знімок за 1–2 с без нового звуку та ще один після 4 с. Перший має містити `live=[none]`, попередній ID і позицію та меншу `freshness`. Другий має містити `memory=[none]`. Для перешкоди порівняй тестовий свист з тієї самої позиції до й після ввімкнення Cube на хості. Очікувана сила за перешкодою — близько 30% попередньої. За межами 18 м нова подія не має замінити спогад.

Поверни рядки `[P3-05 AUTO]` або `[P3-05 MANUAL]` з Console хоста або з `%LOCALAPPDATA%/Unity/Editor/Editor.log`, клієнтський лог, а також скриншот Inspector під час голосу й кроків, якщо ID або позиція неоднозначні. Код кімнати не потрібен у звіті.
